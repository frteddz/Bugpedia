# Bugpedia

In-game encyclopedia of known Minecraft bugs.

Pick your game version and loader, and Bugpedia shows you which known
bugs affect you, with workarounds and the version that fixes them. No
more alt-tabbing to check if something is a bug or just you.

## Features
- Filter by version, loader, and category
- Search
- Workarounds and fix versions
- Bug list updates on its own
